Authentication

Signup

Register a new team and generate API key.

  • Validates team name and email uniqueness
  • Generates secure API key
  • Sends welcome email with API key
  • Returns API key (shown only once)
Request Body schema: application/json
required
team_name
required
string (Team Name) [ 3 .. 100 ] characters

Team name (alphanumeric, 3-100 characters)

team_email
required
string <email> (Team Email)

Team email address

Responses

https://campaignx.inxiteout.ai/api/v1/signup

Campaigns

Send Campaign

Submit a new marketing campaign to a targeted customer cohort.

- Requires: Valid API key in header
- Rate Limit: 100 calls/day per team
- Customer IDs: List of IDs validated against the customer cohort. Max 5000 unique IDs.
Request Body schema: application/json
required
Subject (string) or Subject (null) (Subject)

Email subject (required for Email). Supports text and emojis. Max 200 characters.

body
required
string (Body) [ 1 .. 5000 ] characters

Campaign message body. Supports text, emoji (UTF-8), and URLs. Max 5000 characters.

list_customer_ids
required
Array of strings (List Customer Ids) non-empty

List of unique customer IDs to contact. Customer IDs passed must be present in Customer Cohort.

send_time
required
string (Send Time)

Planned send time in format 'DD:MM:YY HH:MM:SS' (IST). Must be a future time.

Responses

https://campaignx.inxiteout.ai/api/v1/send_campaign

Reports

Get Report

Retrieve campaign report data.

- Requires valid API key
- Rate limited to 100 calls/day
- Validates Campaign ID
- Returns report data as JSON including invokation details, customer responses, and Boolean flags for email opened (EO) and email clicked (EO)
query Parameters
campaign_id
required
string (Campaign Id)

Campaign ID to retrieve report for

Responses

https://campaignx.inxiteout.ai/api/v1/get_report
